# AMARI Experience · Invitación para marcas

Página para invitar a marcas a sumar sus productos a los encuentros de AMARI Experience.

- `index.html`: la página completa (estilos y código incluidos).
- `img/`: fotos, logo y emblema.

## Links personalizados

Agregá `#amari-x-` y el nombre de la marca al final del link (con guiones en lugar de espacios):

`https://tinavolpem.github.io/amari-marcas/#amari-x-natura` → "Una invitación para Natura"
